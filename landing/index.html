Setup

Zero to bot in three moves.

01

Pair your number

Start a session, then link your WhatsApp with a pairing code or QR. Keep the credentials private.

npm install
OWNER_NUMBER=2348012345678 \
PAIRING_NUMBER=2348012345678 npm start
02

Deploy the bot

Run it on a VPS, a process manager, or any host that keeps a Node process alive.

npx pm2 start index.js --name reverse-bot
03

Chat with it

Send a command from any chat you're in. The bot answers on the same number you paired.

Modules

One prefix. Full rack.

[core]

ping, menu, echo, owner info, and an owner-only restart command.

[groups]

Group info, mention-all, and admin tools such as removing members.

[plugins]

Drop a file into the plugins folder and it loads on the next start. Each plugin exports its commands.

[media] soon

Downloads, stickers, and image tools are planned as plugins on the same loader.

[status]

A live dashboard and a /health endpoint for uptime checks.

[access]

Public or private mode. Owner-only and group-only checks on each command.
